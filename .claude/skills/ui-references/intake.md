# Adding a new reference site

When Ben shares a new site:

1. **Visit it** (fetch the page; if it's JS-rendered and returns nothing, say so and ask Ben for a screenshot or the docs URL).
2. **Find out:**
   - What it is (component library, motion, template, tool, research reference).
   - Stack (React version, Tailwind v3 or v4, shadcn registry or not, Framer Motion, React Aria, plain CSS).
   - How you pull from it: MCP server, agent skill, shadcn registry, npm package, copy-paste, or reference only.
   - Cost and license (free/MIT, paid Pro, mixed) and any AI-use opt-out (e.g. `noai` meta tag).
3. **Add an entry to `catalog.md`** under the right heading, in the existing format
   (What / Use / Cost / Fit / Watch). Keep it to 4–6 lines. Only state install commands you saw on the site.
4. **Update `check-in-map.md`** if it's the best (or a strong second) source for any row, or add a new row.
5. **Don't install anything yet.** List any MCP or skill it offers and ask Ben before adding it.
6. Update the "Last reviewed" date at the top of `catalog.md`.
