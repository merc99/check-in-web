# UX profile: Check-in

Read by the skills in `.claude/skills/` (anti-slop, colour-palette, motion, typography, ux-audit and the rest).
Filled in for this project, so there's no need to run the setup wizard.

## Aesthetic reference
**Custom: Apple Native base, with Things 3 cheerfulness.**
- Density: generous. Large hit targets (44px min), calm spacing, unified radii (10 / 16 / 22 / full).
- Borders and elevation: 1px subtle borders first, soft diffused shadows second. Dark mode uses edge lighting.
- Color: warm neutral canvas, one interactive accent (mint, the `primary` token). Crew hues are content color, not chrome color (see below).
- Typography: Bricolage Grotesque for display and big numbers, Geist for UI and body. Tight tracking on headings, tabular numbers.
- Motion: chrome is short and calm (150–200ms, ease-out in, ease-in out). Delight moments may spring (see below).
- Modes: light and dark, both first-class. Dark by default; Settings switches to light or the system. Light mode is warm paper.

## Playful layer (scoped exceptions, deliberate, not slop)
These are the product's personality. They are allowed **only** in the places listed. Everywhere else, the hard rules apply.
1. **Crew hues as content color.** Each crew has one hue. It may tint: the radial glow at the top of the feed, the crew hero card (single-hue gradient), the crew's avatar badges and its tag chips. Unlocked achievement cards may be filled with their solid hue (foil cards, dark `on-color` text). It never colors buttons, nav or links; that's the primary (mint) color's job. This keeps the 10% accent rule intact.
2. **Tag chips.** Tags are interactive (tap to filter the feed), so they render as tinted chips. Static metadata (timestamps, names, counts) stays plain text.
3. **Delight-moment springs.** Overshoot easing is allowed only on: the check-in submit stamp, the check-mark badge popping onto an avatar, the heart burst, chip selection, rolling digits, and emoji reactions (the picker, the flying landing). These are not chrome. Durations up to 600ms for these, and up to 1s for the milestone reveal (its shake and beam).
4. **Celebration color.** Multi-color is allowed only in the effect moments: the check-in burst (crew hue, mint, lemon, white), the milestone reveal, the invite ticket's holo sheen and the crew-complete aurora frame. Never on a button, nav or a static surface.
5. **The effect system.** `components/fx` and its motion budget in CLAUDE.md ("Effects") are the only effects. Three loops exist, each in exactly one place: the holo sheen on invite tickets, the aurora frame (the one glowing border) on the crew hero while the whole crew is in, and a soft light glint across the feed's crew banner every few seconds. Everything else answers a touch and rests.
6. **Emoji reactions.** Reaction emoji are content people leave, not UI icons, so they don't break the one-icon-set rule. The set is fixed in `lib/reactions.ts`.
7. **Frosted glass (tab dock, toasts).** Allowed because it has a visible 1px border, an opaque fallback when `backdrop-filter` is unsupported, and text contrast that passes AA over any content.

## Banned (from the anti-slop defaults, kept)
- Multi-color or rainbow gradients on buttons (effects in 4 never sit on a button)
- Blur without a visible border and opaque fallback
- Neon glowing borders and glow stacks (the crew-complete aurora frame is the one exception, see 5)
- Cartoon people in empty states (empty states get a heading, one line and an action)
- Decorative icons inside inputs (search, clear and password toggle only)
- Pastel pills around static metadata

## Accessibility
**WCAG 2.1 AA.** Text 4.5:1, large text and UI borders 3:1, 44×44px targets, visible focus (accent ring). Check both modes.

## Voice
**Warm and humancentric.** "Your crew", never followers or friends. No shame, no urgency, no FOMO. Missed days: "yesterday slipped by". Returning users: "Welcome back". Sentence case, verbs on buttons.

## Icons
**Lucide** (`lucide-react`), 1.75px stroke, 20px default. One set only, no emoji as UI icons. A custom Check-in icon set may replace it later; swap in one place (`components/checkin/icon.tsx`).
